- New question type: MAP Number & Symbol Placement.
- Seeded question: Marshall buys a pencil for 12¢ and a sticker for 5¢; answer 17¢.
- Click a token in the lower bank to fill the corresponding number or symbol slot; click a filled slot to return it. RESET clears both slots.

- Teacher Edit supports directions, description and correct answer; default token bank is 12–19, $ and ¢.
